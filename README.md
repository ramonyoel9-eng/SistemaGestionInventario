# Sistema de Gestión de Inventario

## 1. Descripción del proyecto

El Sistema de Gestión de Inventario es un proyecto de software orientado a facilitar el control y la administración de productos, proveedores y movimientos de inventario. Su propósito es organizar la información y contribuir a mejorar el seguimiento de las entradas y salidas de productos.

Actualmente, el proyecto se encuentra en la fase de planificación y definición de la arquitectura inicial.

## 2. Objetivo general

Proponer un sistema informático que permita administrar los productos de un inventario de manera organizada, facilitando el registro, la consulta y el seguimiento de sus movimientos.

## 3. Objetivos específicos

- Definir la estructura inicial del sistema.
- Establecer los requisitos principales de gestión de productos y proveedores.
- Planificar el registro de entradas y salidas de productos.
- Proponer una estructura de base de datos para almacenar la información.
- Organizar las tareas del proyecto mediante GitHub Projects e Issues.

## 4. Tecnologías propuestas

- **Lenguaje de programación:** C#.
- **Interfaz gráfica:** Windows Forms.
- **Base de datos:** SQL Server.
- **Control y seguimiento del proyecto:** GitHub.

Estas tecnologías representan la propuesta inicial y su implementación está pendiente.

## 5. Funcionalidades previstas

1. Registrar productos.
2. Consultar productos.
3. Registrar proveedores.
4. Registrar entradas y salidas de productos.
5. Consultar el inventario disponible.

Las funcionalidades se encuentran pendientes de desarrollo y validación.

## 6. Arquitectura inicial

Se propone una arquitectura por capas:

- **Presentación:** interfaz gráfica para la interacción con los usuarios.
- **Lógica de negocio:** validaciones y reglas para las operaciones del inventario.
- **Acceso a datos:** comunicación entre la aplicación y la base de datos.
- **Base de datos:** almacenamiento de productos, proveedores y movimientos.

Esta estructura busca facilitar la organización, el mantenimiento y las futuras modificaciones del sistema.

## 7. Gestión del proyecto

El seguimiento se realiza mediante GitHub Projects e Issues, donde se registran las tareas previstas, su estado y los avances de planificación.

## 8. Estado actual

El proyecto se encuentra en su etapa inicial de planificación. La definición de la arquitectura se está documentando y las funcionalidades, la integración con la base de datos y las pruebas de funcionamiento están pendientes.

## 9. Próximas actividades

- Completar la definición de la arquitectura.
- Diseñar la estructura de la base de datos.
- Desarrollar los formularios y funcionalidades.
- Integrar la aplicación con SQL Server.
- Realizar pruebas de funcionamiento y corregir errores.
